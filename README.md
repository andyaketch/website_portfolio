# AA Robotics Portfolio

An interactive, responsive landing page showcasing autonomous systems, robotics hardware, and real-time edge intelligence projects.

## Live Demo

Explore the live site: [AA Robotics on GitHub Pages]([https://<your-username>.github.io/<your-repo-name>/](https://andyaketch.github.io/website_portfolio/))

## Features
- **Dynamic Content Injection**: Testimonials and project cards rendered dynamically from JavaScript data structures using template literals.
- **Responsive Multi-Column Layouts**: Adapts across mobile, tablet, and desktop views using CSS Grid and Flexbox.
- **Interactive Animations**: Card lift transitions, image scale on hover, and smooth visual feedback.
- **Automated Deployment**: Built and continuously deployed via GitHub Actions workflows to GitHub Pages.

## Technologies Used

- **HTML5**: Semantic document structure and accessible metadata.
- **CSS3**: Custom layout systems (Flexbox, Grid), animations (`@keyframes`), and responsive viewport sizing.
- **JavaScript (ES6+)**: DOM manipulation, template literals, and array iteration methods (`forEach`).
- **GitHub Actions & Pages**: Automated continuous deployment pipeline.
